# Tidal Frame Systems — website

One-page static site. No build step, no external libraries, no tracking.

- `index.html` — page copy
- `styles.css` — layout and colors
- `assets/` — hero image, logo mark, favicon, social preview image
- `.nojekyll` — tells GitHub Pages to serve the files as-is

Live at https://tidalframesystems.github.io/
